# Welcome to X-Tech GitHub Collaboration Exercise

This is the exercise repository for the first workshop. We will practice GitHub collaboration here and will not modify the official website.

## To-Do for Today

1. Leave your GitHub username and what you want to learn in the check-in Issue.
2. Add your own member introduction in the `members/` folder.
3. Create a branch for your changes and submit a Pull Request.
4. Review your peers' Pull Requests.

## Member Introduction Format

Please refer to `members/example.md` and only submit your own member file.

## Collaboration Workflow

Issue → Branch → Commit → Pull Request → Review → Merge
